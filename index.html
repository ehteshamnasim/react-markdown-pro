react-markdown-pro

An enhanced React component for rendering Markdown content with support for images, syntax-highlighted code blocks, and LaTeX math equations.

npm install react-markdown-pro

Powerful Features

Everything you need for rich Markdown rendering in your React applications

Rich Markdown Rendering

Supports standard Markdown syntax including headings, lists, links, blockquotes, and more—with customizable styles to match your application's design.

GitHub Flavored Markdown

Enhanced support through remark-gfm, enabling tables, task lists, strikethrough, and other GitHub Flavored Markdown features your users expect.

LaTeX Math Support

Render inline and block math expressions using KaTeX, making it easy to display complex mathematical notation for educational applications.

Syntax Highlighting

Code blocks are beautifully rendered with syntax highlighting via react-syntax-highlighter, with line numbering and customizable themes.

Image Support

Automatically render images via Markdown with responsive styling, ensuring they display correctly on all devices and screen sizes.

Clipboard Integration

Built-in copy-to-clipboard functionality for code snippets, making it simple for users to copy and share code examples.

Elegantly Simple API

Get started in just a few lines of code

Basic Usage

import React from 'react';
import MarkdownPro from 'react-markdown-pro';

function Example() {
  // You can use simple string content
  const simpleExample = "# Hello World\n\nThis is **bold** text and *italic* text.";
  
  return (
    <div className="container">
      <MarkdownPro>{simpleExample}</MarkdownPro>
    </div>
  );
}

export default Example;

Hello World

This is bold text and italic text.

Perfect for Math Content

Easily render LaTeX equations in your React applications

import React from 'react';
import MarkdownPro from 'react-markdown-pro';

function MathExample() {
  const mathExample = "Solve for $x$: $2x + 3 = 7$.\n\nThe quadratic formula is: $$x = \\frac{-b \\pm \\sqrt{b^2 - 4ac}}{2a}$$";

  return (
    <div>
      <h2>Math Example:</h2>
      <MarkdownPro>{mathExample}</MarkdownPro>
    </div>
  );
}

Which renders like this:

Solve for x: 2x + 3 = 7.

x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}

Note: This website shows a representation of how the equations would appear when rendered by the actual component.
